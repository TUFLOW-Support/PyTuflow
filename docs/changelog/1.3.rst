ARR to TUFLOW
^^^^^^^^^^^^^

A tool to automate the fetching and processing of data from the `Australian Rainfall and Runoff (ARR) datahub <https://data.arr-software.org/>`_ into TUFLOW rainfall boundaries.

This tool is the successor to the `TUFLOW QGIS plugin tool <https://wiki.tuflow.com/QGIS_ARR_to_TUFLOW>`_ of the same name that existed prior to the 2026.2.0 plugin release. The tool has been upgraded to work with the 2026 v1 update of the datahub. It can be run via the CLI or by using the ARR classes and functions directly. The configuration in either case is defined in a configuration JSON file.

:ref:`pytuflow-arr documentation <pytuflow-arr>`

**CLI Example**

The CLI uses the ``pytuflow-arr`` script with a single, or list of, configuration files as the only arguments.

.. code-block:: bash

    pytuflow-arr config.json [config2.json ...]

**Code Example**

The example below shows the equivalent code used in the CLI script for a single site.

.. code-block:: python

    from pytuflow import ArrConfig, ArrApiClient, ArrEngine
    from pytuflow.arr import write_outputs, write_working_data

    config = ArrConfig.from_file('/path/to/config.json')
    client = ArrApiClient()
    response = client.fetch(config)
    engine = ArrEngine(config, response)
    results = engine.run()
    write_outputs(config, results)
    write_working_data(config, response, engine)
