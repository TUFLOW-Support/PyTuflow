Changelog for 1.3
=================

1.3.1
-----

Release date: XX November 2026

- :ref:`pytuflow-arr` - The option for a user to supply climate change scenario names has been added. Custom scenario names are optional and if
  not provided, the tool will default to ``<baseline_year>_<ssp>``.
- :ref:`pytuflow-arr` - The output AEP notation is now kept consistent for events > 1% AEP. For example, previously the 0.1% AEP event would incorrectly use the name 1000yr.
- :ref:`pytuflow-arr` - The output AEP and durations will now use consistent padding. For example, the 10 minute event will be ``0010m`` if the ``1440m`` (24 hr) event is
  included so that the name length is the same.

Release date: 05 November 2026

ARR to TUFLOW
^^^^^^^^^^^^^

A tool to automate the fetching and processing of data from the `Australian Rainfall and Runoff (ARR) Data Hub <https://data.arr-software.org/>`_ into TUFLOW rainfall boundaries.

This tool is the successor to the `TUFLOW QGIS plugin tool <https://wiki.tuflow.com/QGIS_ARR_to_TUFLOW>`_ of the same name that existed prior to the ``2026.2.0`` plugin release. The tool has been upgraded to work with the **2026 v1** update of the data hub. It can be run via the CLI or by using the ARR classes and functions directly. The configuration in either case is defined in a configuration JSON file.

:ref:`pytuflow-arr documentation <pytuflow-arr>`

**CLI Example**

The CLI uses the ``pytuflow-arr`` script with a single, or list of, configuration files as the only arguments.

.. code-block:: bash

    pytuflow-arr config.json [config2.json ...]

**Code Example**

The example below shows the equivalent code used in the CLI script for a single site.

.. code-block:: python

    from pytuflow import ArrConfig, ArrApiClient, ArrEngine
    from pytuflow.arr import write_outputs, write_working_data

    config = ArrConfig.from_file('/path/to/config.json')
    client = ArrApiClient()
    response = client.fetch(config)
    engine = ArrEngine(config, response)
    results = engine.run()
    write_outputs(config, results)
    write_working_data(config, response, engine)


TUFLOW-SWMM GPKG Time Series Support for Polygon Data
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Starting with TUFLOW 2027.0, TUFLOW-SWMM writes time series data for polygon features (catchments) in GPKG format. This allows users to plot the results from SWMM catchments within the TUFLOW-SWMM model.

**Code Example**

.. code-block:: python

    from pytuflow import TPC

    res = TPC('/path/to/tpc_filename')
    df = res.time_series('subcatchment_name', 'dataset_name')
